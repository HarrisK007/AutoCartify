# AutoCartify

A React admin panel for an online store: a dashboard with sales charts and summary cards, and an orders page listing each order's customer, date, total and status.

## Pages

- **Dashboard** (`/`): order and query summary cards, plus a sales trend chart built with Chart.js
- **Orders** (`/orders`): table of orders with ID, customer, date, total amount and status

## Run it

```bash
npm install
npm start
```

Then open http://localhost:3000.

## Stack

React 19 · React Router · Bootstrap 5 · Chart.js · Font Awesome
